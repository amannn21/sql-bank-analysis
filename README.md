# Bank Customer Analysis (SQL)

## Objective
Analyze bank customer data to understand customer distribution, balance trends, and subscription behavior.

## Tools Used
- SQL (PostgreSQL)

## Key Analysis
- Customer segmentation by job and age
- Balance analysis across different groups
- Loan distribution
- Subscription (conversion) analysis

## Key Insights
- Certain job categories have higher average balances
- Subscription rates vary significantly across customer segments
- Age group plays a role in customer behavior

## Conclusion
SQL analysis helps identify high-value customer segments and improve targeting strategies.
